# داشبورد مالی — نسخهٔ Streamlit (توسعهٔ کد قبلی)

این پوشه همان برنامهٔ قبلی شماست که در Streamlit اجرا می‌شود و ساختار داده، ورود با رمز و ذخیره‌سازی `data.json` / GitHub آن حفظ شده است. تغییرات این مرحله:

| قابلیت | توضیح |
| --- | --- |
| 🔀 **جفت ارز مصنوعی** | ساخت جفت از هر دارایی، صندوق طلا یا نرخ دلار دارای تاریخچه؛ نمودار نسبت، مقایسهٔ نرمال‌شده (پایه = ۱۰۰) و جدول نسبت‌ها |
| 🎨 **اولویت‌بندی سربرگ‌ها** | در تنظیمات (هم در سایدبار و هم صفحهٔ تنظیمات) با دکمه‌های ▲ ▼؛ ترتیب در `settings.nav_order` ذخیره می‌شود |
| ⚙️ **تنظیمات در پنل سمت راست** | سایدبار با CSS به سمت راست منتقل شده و بخش تنظیمات سریع داخل همان پنل است |
| 🌗 **حالت روز/شب خودکار** | بر اساس ساعت تهران و بازهٔ `day_start` تا `night_start`؛ گزینهٔ خاموش/روشن دارد |

تحلیل‌های قبلی هر دارایی و صندوق کامل حفظ شده‌اند: نمودار ارزش کل، نمودار مقایسهٔ قیمت هر واحد (ریال / دلار / نرخ دلار)، سیگنال تله دلار، آمار قیمت و واحد/انس، تحلیل دلاری، سیگنال انس، هشدار تله دلار و ماشین‌حساب آربیتراژ.

## اجرای محلی

```bash
cd streamlit_app
python -m venv .venv
source .venv/bin/activate        # در ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
# اختیاری: رمز و تنظیمات GitHub
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
streamlit run app.py
```

پیش‌فرض رمز: `S@mnet11970` (در `secrets.toml` با کلید `APP_PASSWORD` تغییر دهید).

## استقرار روی GitHub + Streamlit Community Cloud

1. این پوشه را به مخزن GitHub خودتان push کنید. اگر می‌خواهید داده‌ها در همان مخزن ذخیره شوند، `data.json` را در ریشهٔ مخزن نگه دارید.
2. در [share.streamlit.io](https://share.streamlit.io) مخزن را وصل کنید و `streamlit_app/app.py` را به‌عنوان فایل اصلی انتخاب کنید.
3. در بخش **Secrets** مقادیر زیر را وارد کنید:

```toml
APP_PASSWORD = "رمز-شما"
GITHUB_TOKEN = "ghp_..."
GITHUB_REPO = "username/repo-name"
```

توکن GitHub باید دسترسی **Contents: Read and write** داشته باشد؛ فایل داده در مسیر `data.json` شاخهٔ `main` ذخیره می‌شود (همان روش قبلی، همراه gzip در صورت نیاز).
